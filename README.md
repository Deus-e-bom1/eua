# Escola de Avatares — site para Vercel

## Como publicar
1. Envie TODO o conteúdo desta pasta para um repositório no GitHub (não envie a pasta em si, envie o que está dentro dela).
2. Na Vercel: "Add New..." → Project → importe o repositório → Deploy. Não precisa mudar nenhuma configuração.
